# Advert footage (not app code)

Screen recordings of the Shtëpia.ime app, for the iPhone advert assembled on
Higgsfield. Filmed from the app's own web build against the test backend:
sample listings and names, no real user data. `s14` redraws the launch door
animation from the logo's paths (`src/features/brand/doorLogo.js`).

`scenes/manifest.json`: seconds into each clip where the screen is ready.
This branch can be deleted once the advert is final.
